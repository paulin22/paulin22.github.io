02

Public TypeScript Accounting OS

Central Books

The repository README presents this as Clover Books: an accounting platform for small businesses, freelancers, and agencies, with an AI Companion described as a control tower. Deterministic checks run first. Model output is framed as suggestion, with a person approving before books change.

The TypeScript surface is two React apps — customer and admin — plus a shared UI package. Pages cover receipts, invoices, expenses, banking, journal entries, inventory, profit and loss, cash flow, team roles, and tax. The active API in the same repository is Rust (Axum, SQLx, SQLite). A legacy FastAPI service remains for reference. Docs in the repo describe a Canada and US tax engine.

  • React 18
